# 📱 Mobile Sales Dashboard – Power BI

## 📊 Project Overview

An interactive **Power BI Mobile Sales Dashboard** developed to analyze mobile sales performance and provide insights into sales, transactions, units sold, pricing, brands, customer ratings, and payment methods.

## 🎯 Objectives

- Analyze overall mobile sales performance
- Compare sales across different brands
- Track yearly quantity trends
- Analyze customer rating distribution
- Understand transaction patterns by payment method
- Enable interactive analysis using slicers

## 📌 Key KPIs

- **Total Sales:** 68.28M
- **Total Transactions:** 331
- **Average Price:** 41.32K
- **Total Units Sold:** 2K

## 📈 Dashboard Visualizations

- **Total Quantity by Year**
- **Total Sales by Brand**
- **Customer Age by Rating Status**
- **Transactions by Payment Method**
